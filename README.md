# Al-Tazaj Customer Service Chatbot

## Description
An AI-powered customer service chatbot developed for Al-Tazaj, a Saudi Arabian fast-food restaurant chain, using Microsoft Copilot Studio.

The chatbot helps customers access menu information, locate branches, and track orders to improve customer satisfaction and operational efficiency.

## Features
- **Welcome Message:** Greets users and displays available options.
- **Show Menu:** Provides a link to the restaurant menu.
- **Find a Branch:** Provides a link to branch locations.
- **Track My Order:** Allows users to check their order status.
- **Input Validation:** Rejects invalid order numbers and displays an error message.

## Technologies Used
- Microsoft Copilot Studio
- Artificial Intelligence (AI)
- Natural Language Processing (NLP)
