# Al-Tazaj Customer Service Chatbot

## Project Description
This project presents a customer service chatbot developed for Al-Tazaj, a Saudi Arabian fast-food restaurant chain, using Microsoft Copilot Studio.

The chatbot aims to improve customer service by automating responses to common inquiries, providing access to restaurant information, and assisting customers with order tracking.

## Problem Statement
Al-Tazaj faces several customer service challenges, including delayed responses, high volumes of repetitive inquiries, and limited service availability. These challenges can affect customer satisfaction and operational efficiency.

## Proposed Solution
An AI-powered chatbot was developed to automate common customer interactions, reduce the workload of customer service staff, and provide customers with quick access to essential information.

## Key Features
- **Welcome Message:** Greets customers and presents the available options.
- **Menu Access:** Provides a link to the restaurant menu.
- **Branch Locations:** Directs customers to information about Al-Tazaj branches.
- **Order Tracking:** Requests an order number and displays the corresponding order status.
- **Input Validation:** Checks order numbers and displays an error message when the entered number is invalid.

## Technologies Used
- **Microsoft Copilot Studio:** Used to develop the chatbot and configure its conversation flows.
- **Artificial Intelligence (AI):** Supports automated customer interactions.
- **Natural Language Processing (NLP):** Enables the chatbot to process customer inquiries.

## Chatbot Workflow
1. The chatbot welcomes the customer and displays the available options.
2. The customer selects an option to view the menu, find a branch, or track an order.
3. For menu and branch inquiries, the chatbot provides the relevant links.
4. For order tracking, the chatbot requests an order number and validates the input.
5. If the order number is valid, the chatbot displays the order status. Otherwise, it returns an error message.
